# Мониторинг системных ресурсов

Простой Bash-скрипт для периодического мониторинга основных ресурсов Linux.

## Что делает скрипт

Скрипт каждые 5 секунд записывает в файл `monitor.log`:

- текущие дату и время;
- время работы системы и среднюю нагрузку;
- использование оперативной памяти;
- использование дискового пространства.

## Требования

- Linux;
- Bash;
- команды `uptime`, `free`, `df`, `date`, `sleep`.

## Использование

Сделать скрипт исполняемым:

```bash
chmod +x script.sh
```

Запустить:

```bash
./script.sh
```

Для корректной остановки нажать `Ctrl+C`.

## Файлы проекта

- `script.sh` — скрипт мониторинга;
- `.gitignore` — исключает рабочий файл `monitor.log` из Git;
- `sample_output.txt` — пример вывода скрипта.
